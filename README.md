🌐 Internet Speed Tracker


Python • Tkinter • Speedtest API

A lightweight desktop application to measure real-time internet speed with a clean GUI.

📌 Overview

Internet Speed Tracker ek Python desktop application hai jo users ko unki download speed, upload speed, aur ping latency real-time me check karne ki facility deta hai.

Ye project Tkinter GUI ke sath banaya gaya hai, jisse ek simple, fast aur user-friendly interface milta hai — perfect for beginners as well as practical use.

🎯 Features

✅ Real-time Download Speed measurement

✅ Real-time Upload Speed measurement

✅ Ping / Latency detection

✅ Clean & minimal Tkinter GUI

✅ One-click speed test

✅ Lightweight & fast execution


🧠 Tech Stack

⚙️ Installation & Usage
1️⃣ Clone Repository
git clone https://github.com/akhileshsinghp1008/Internet-speed-testing
cd internet-speed-tracker

2️⃣ Install Dependencies
pip install speedtest-cli

3️⃣ Run Application
python main.py

🚀 How It Works

Application speedtest-cli library se nearest server select karta hai

Download & upload speed calculate hoti hai

Results GUI pe Mbps me display hote hain
